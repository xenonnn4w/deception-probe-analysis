# Provenance and contribution boundaries

The historical experiments originated in a time-limited research assessment, using supplied research questions, a preprint, and a `deception_detection` codebase. This folder reorganizes the resulting analysis into a personally maintained project. It should not be represented as employment, affiliation, an original benchmark, or wholly independent project origination.

## Included

- Three historical aggregate CSV tables, renamed for a standalone analysis project and preserved byte-for-byte. SHA-256 hashes are recorded in `data/manifest.json`.
- A newly written standard-library analysis/validation script with optional plots.
- A retrospective report distinguishing measurements, interpretations, and unexecuted follow-up ideas.
- Three original August figures, preserved byte-for-byte and hashed in `data/manifest.json`. The layer-geometry image is a historical artifact; its underlying centroid arrays are not included, so it cannot be regenerated from the aggregate CSVs.

The original submission contains experiment launch scripts, tables, plots, a small generation pilot, and a written analysis. The existence of those artifacts supports describing the completed work, but does not by itself establish personal authorship of every underlying implementation. The original exercise allowed AI assistance. Contributors should be able to explain their own reasoning, interventions, and code changes without claiming sole authorship of supplied or assisted work.

## Deliberately excluded

- The supplied probing framework: no redistribution license was found in the inspected package.
- Assessment questions, supplied papers, and presentation templates.
- Session transcripts, provider configuration, execution logs, and account information.
- Raw benchmark prompts, generated completions, model checkpoints, activations, and gated datasets.

Organization names and assessment branding are not needed in the project title or narrative. Omitting branding does not change the origin or licensing of reused materials. An external local packaging record retains the source paths for traceability and is not part of this folder.

## Licensing

No LICENSE file has been added: a single blanket license would incorrectly imply that redistribution rights for all historical inputs have been established. Determine the applicable rights before choosing a public license. References are acknowledgements, not permissions.
